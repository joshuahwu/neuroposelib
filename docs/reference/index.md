# API Reference — neuroposelib

This page provides a short overview and quickstart for the `neuroposelib` package.

Import neuroposelib as:

```
import neuroposelib as npl
```

For the full API documentation see the per-module pages linked in the sidebar.

**Quick links**

- `Connectivity` - defines the skeleton structure and color parameters for the 3d poses
- `DataStruct` — data container used across the package
- `Embed` — create and apply embeddings
- `GaussDensity` / `Watershed` — density maps and density-based clustering
